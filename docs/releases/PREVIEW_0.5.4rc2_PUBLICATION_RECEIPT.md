## Actual capabilities and remaining limits

Open **Overview → Open garden handover** or **Open garden campaign**; the complete
fictional bundle is included. The source ZIP's
`examples/offline-garden/README.md` provides the walkthrough. Local sources,
casebooks/handover, campaign edits, saved records, Word/JSON export and restore
need no account, internet, model download or successful hosted generation.

Optional native NeuroForge assistance follows the exact compact public profile:
buffered text, 1–128 output tokens, a 2,048-byte final question, bounded recent
history and a separate 512-token prompt budget. The shared 57 fixtures and native
interface failure tests establish protocol/recovery behavior. One historical
fictional short-answer acceptance is retained separately; no new hosted generation
was requested in this release cycle. General native assistant quality, long native
recipes, caller system messages, streaming/tools/media and exact public token
preflight remain unsupported. Live ChatGPT generation remains unqualified.

Other eight native targets, publisher signing/notarisation and customer-device
acceptance remain outstanding. Packages are unsigned/not notarised; never disable
OS protections. Local work/backups are unencrypted and intended for one trusted
user. No hosted multiuser CRM, automatic grant submission or autonomous sender is
introduced. The latest bounded product assessments remain below 10/10; release
integrity is not a claim of a perfect user experience.
