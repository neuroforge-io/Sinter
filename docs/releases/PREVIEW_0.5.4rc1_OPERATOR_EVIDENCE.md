## Limits that remain visible

Long native research, letters and reviews are unsupported; local work remains
available and an explicit capable-provider choice is required. Exact public token
preflight, native streaming, caller system messages, tools and media are not
qualified. An incomplete or uncertain generation is never automatically replayed.

The core is a local, single-trusted-user workbench. Casebooks and campaigns are
separate records with deliberate transfer. Backups are unencrypted. No automatic
submission, messaging, hosted collaboration or grant-eligibility verification is
claimed. Scope-limited independent scores remain UX 7.5/10, functionality 8.5/10
and aesthetics 7.5/10; no aspect is claimed to be 10/10.
