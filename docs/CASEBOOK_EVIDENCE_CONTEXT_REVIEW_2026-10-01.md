# Retained evidence coverage and local context — 1 October 2026

Current `0.5.4rc4.dev0` source makes two practical gaps visible in source-only
casebook reports: a chosen source may supply no quotation for a question, and a
quotation may stop before relevant table cells. This is a local inspection tool;
it does not improve lexical retrieval or establish an answer. Published RC3
assets, historical reports and installed qualification remain unchanged.

## Using the evidence view

Open a source-only casebook report and choose **Evidence**. Each question shows
its recorded source choice and, when records can be resolved, how many supplied
or chosen source identities have an exact retained quote. Expand the sources
without a quotation to inspect their recorded identities. An unused original
may be absent from this report even though its source record is retained; inspect
the matching historical project or backup. A newer project is not a substitute.

Expand a quotation and choose **Inspect surrounding text** to show up to 600
Unicode code points on each side, or **Open original source** to inspect the
retained body. Sinter checks the actual UTF-8 SHA-256 against both recorded source
hashes before these actions. Missing bodies, ambiguous identities, changed text
or unavailable local digest support refuse inspection without substituting data.
Windows may still end inside a section or table; inspect the full original when
needed. The quotation's wording and original offsets remain unchanged.

Unknown question wording, malformed passage lists and unresolved references are
shown as unavailable. An explicit empty passage list is distinct from an unknown
one. Counts describe exact retained quotation matches, not relevance, authority,
whole-source review, eligibility or factual correctness.

Additional original text stays local. It is not appended to saved report content,
Word documents, evidence quotations or the optional AI preview. Inspection sends
no new evidence request, saves no revision and never replays generation. To use
new material in an application answer, review the original and make a deliberate
new draft; this pass does not add a manual passage-selection contract.
