# RC4 external host observations

These source tools preserve independently observed **before and after** identities of the external runtime used by the future installed Linux qualification. They have no installed admission of their own. Source controls use fictional files and inert owners; they do not prove that an installer or customer workflow passed.

The boundary remains a trusted host, Playwright library and Docker daemon. Host executable payloads are deliberately external: Chromium and Playwright Node exceed the public 64 MiB member or 256 MiB bundle limits. Those evidence limits remain unchanged. Hashing a host file has a separate existing 512 MiB read limit and does not put that file in an evidence bundle. No mapped-library completeness, daemon attestation, compute availability or quality claim follows from matching fingerprints.

`tools/rc4_host_tools.py` provides bounded file fingerprint reads, independent read aggregation and a closed pure before/after parser. `fingerprint(path)` returns the actual resolved regular file path, complete byte count and SHA-256 without retaining its payload. It refuses changed or incomplete reads. `observe(callbacks)` attempts every selected read, retains all errors and returns the original first exception; a later owned-file close failure cannot replace an earlier read failure.

The replacement owner now emits `sinter-rc4-replacement-owner/v2`. Its host record has schema `sinter-rc4-host-tools/v1`, the exact boundary string, independent `before` and `after` snapshots, and `after_errors`. Each snapshot binds the Docker executable resolved through the child environment's fixed PATH, explicitly selected Chromium, actual collector Python, bundled Playwright Node, bundled driver CLI, collector source bytes, installed Playwright version, Python launch label and owned browser-temp label. The collector child receives the existing closed environment without caller `PLAYWRIGHT_NODEJS_PATH` or account credentials, so the selected Node/CLI belong to the library actually used by that fixed collector. Original Docker/collector argv, complete streams and process observations remain separately required. This pass adds no direct replacement Chromium/Node process-stream observation; those Playwright-managed internals remain within the stated trusted-library boundary.

Every prior replacement gets its own complete before snapshot and actual after reads following the existing removal attempts. After reads run independently. Failed reads refuse qualification even when other identities remain readable. The first owner/read exception and every later publication fault survive in `outer-host-failed.json` or the complete unpublished evidence carried by `EvidenceFailure`; the command-line failure path renders that full structured record to its owning stderr. The original-tree verifier requires the new pair and independently binds it to the current exact selected host. Old before-only metadata or booleans cannot satisfy the new schema.

Native handoff browser evidence now uses `sinter-rc4-native-handoff-browser/v2`. It requires actual selected Chromium and actual observed Playwright driver executable hashes before launch and after owned cleanup. The Chromium argv, full stdout/stderr, reaped owner and actual Node PID/executable observation are preserved. Missing, changed, null or untyped after hashes refuse. The existing Docker before/after schema remains; its after read and both sidecar publications now run independently, preserving the first handoff failure rather than allowing a later hash or write failure to replace it.

Recovery already retains actual after hashes and remains unchanged. Legacy contracts, historical receipts and released packages remain unchanged. Original failures remain evidence. A successful pure read or source regression is not installed, release or public historical semantic qualification.
