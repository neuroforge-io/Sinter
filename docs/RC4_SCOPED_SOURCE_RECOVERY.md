# Scoped project source recovery

`tools/rc4_scoped_recovery_source.py` is a functional Linux **source-only** rehearsal. It creates fictional local work, captures the OS opener instead of opening a physical browser, pauses the watch scheduler, and rejects model/key/network use. It never admits a version, prior installer, platform or release. RC3 recovery/v1 and the existing source-v1 campaign receipt keep their original meanings.

Use an owned frozen source tree with a complete SHA-256 file inventory and its exact base commit. The command requires an existing development Python environment, Playwright and Chromium; `--help` opens no workspace. Output must be a fresh directory outside the source. Select a private home directory for `TMPDIR`.

```text
python -B tools/rc4_scoped_recovery_source.py --source-manifest /private/source-manifest.json --source-manifest-sha256 SHA256 --source-commit COMMIT --output /private/new-proof --chromium /existing/chromium
```

The command runs two separate profiles. Its first profile reruns the existing campaign-source recovery: six actual stops/reopens, held/resumed/closed route states, unknown/unassigned owners, unconfirmed dates, stale source warnings, two distinct complete offline restores, save conflicts, a committed save with a lost reply, and an uncertain quit. Keep working retains dirty inputs; a later explicit user action retries; no automatic replay is accepted. Those campaign behaviors remain campaign evidence, not inferred project behavior.

The new scoped-project profile operates the real phone interface. It imports three complete fictional originals, inspects them, selects one source for the first question, explicitly selects none for the second, and leaves the third searching all supplied sources. It saves v2, shows the visible older-reader warning, blocks changed question wording without posting or clearing choices, and captures the complete stale local backup. A useful source-only volunteer handover retains question choices, passage identities/ranges/citations and full originals. Human partial wording is applied and saved separately under a report ID; review status stays draft. The actual Word package must match every OOXML part from that exact applied text. A campaign task is edited manually, retaining original unknown owners, proposed dates, costs and historical evidence.

A separate scoped control checks a real two-window save conflict, retained local wording/full backup, unchanged stored records and no automatic replay. Four real source process lifetimes then demonstrate cold reopen, export, stopped-save refusal, complete actual clipboard text and denied-clipboard manual selection. Clipboard and manual payloads restore as distinct saved IDs, without rewriting the original project, report or campaign. A typed live-file snapshot is retained and checked against the seeded original rows, schema, persistent metadata and preferences before any post-stop Runtime/NativeController/CLI initialization. A changed fixture refuses without reopening or repair; this conservation rehearsal does not qualify a migration. All stopped processes retain full diagnostic bytes/hash/count and the bounded reversible sample; only the exact source-bound normal browser notice is accepted.

Protocol evidence is separate from UI evidence. Six actual HTTP routes test missing, wrong, duplicate-valid, valid-then-wrong and wrong-then-valid capability headers: scoped read, validation, scoped save, v1 resave over stored v2, build and optional draft. All thirty refuse with friendly scope-preservation text before queue/connection work; typed SQLite rows and preferences remain exact. The capable browser's read and validation succeed. Headers are set per request, never globally defaulted.
