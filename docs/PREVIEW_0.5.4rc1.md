## Useful without a model

Use the [fictional garden bundle and walkthrough](../examples/offline-garden/README.md).
Casebooks retain original documents and literal citations; campaigns retain
editable actions, unresolved owners, proposed dates and historical evidence.
They are separate local records, with deliberate transfer rather than automatic
synchronization. Save and export before quitting. Restoring opens a new unsaved
copy; optimistic revisions prevent a stale tab overwriting newer work.

The core works without an API key, internet, downloaded model or successful
generation. Local data and backups are unencrypted. Sinter is a single trusted
user's workbench, not a hosted collaborative CRM or an autonomous sender.

## Optional AI

[Native compatibility](NATIVE_API_COMPATIBILITY.md) documents exact public
fixtures and bounded request/response validation. Short source answer sends a
previewed excerpt and question. Byte admission is not proof of fitting the
512-token prompt budget, compute availability or answer quality. No public exact
token preflight is currently qualified. Unsupported long native recipes retain
their inputs and require a smaller selected task or an explicitly configured
capable provider.

[Assistant evidence](ASSISTANT_VALIDATION_2026-09-30.md) distinguishes account
access, useful partial text and verified completion. No uncertain request is
automatically replayed; local reports remain usable after provider failure.

asset hashes and installed runtime/workflow receipts. Copied fictional upgrade
testing checks v0.5.3 work, settings and explicit model selection. The full
publisher still requires all nine platform receipts. A Linux-only preparation

Candidate packages are unsigned/not notarised community previews. Ad-hoc macOS
integrity signing does not identify a verified publisher. Never disable operating
system protections to install them. [Installation guidance](INSTALLATION.md)
describes the declared matrix; actual candidate receipts establish what ran.

Release promotion requires the advertised platform's installed and upgrade
evidence, a useful local walkthrough and clear unsupported-feature representation.
Hosted AI quality and availability remain optional, separately reported limits.

## Independent critic

The scoped offline source/campaign assessment is UX **7.5/10**, functionality
**8.5/10** and aesthetics **7.5/10**. The critic used actual local source,
save/reopen/restore/conflict and compact-source interface journeys. It found and
rechecked delayed-preview, citation, template-switch data-loss and report-title
defects. These fixes do not establish extraordinary design, live assistant
quality, a funding outcome or representative customer acceptance. Long forms and
deliberate transfer between separate records remain usability limits. No aspect
is claimed to be 10/10.
