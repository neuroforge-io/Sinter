This is `0.5.4rc2.dev0` development after `20e0567`. The frozen Linux
`0.5.4rc1` candidate at `cd928ba7561a09c477b3555e64aa6a3c4cc122b4`
and its installed qualification remain separate.

## What an operator can now do

Overview and Getting started offer the complete fictional garden handover and
funding campaign directly. The bundled casebook and campaign are byte-identical
to the agreed `examples/offline-garden/` files. Four sources, unknown costs,
unaccepted owners, proposed dates and historical records remain intact.

Opening a practice copy protects unrelated unsaved inputs with an explicit
replacement decision. Failed loading preserves the current work and requires
explicit retry. Switching the paired editors resumes practice edits, including
an unapplied handover editor. Changing a casebook input clears its current
prepared report; the earlier edited document remains separately recoverable in
My workspace. There is no automatic preparation or model replay on return.

Local pages, persistence and security checks no longer depend on optional model
account callbacks. Host and session checks precede account resolution. Model
routes still capture the selected account identity, while search and scheduled
watches use their separate transport. An expired account alone was already
lazy and was not the reproduced failure; injected account-metadata failure
demonstrated the unnecessary coupling this change removes.

## Adversarial findings still open

The independent entry review rated this bounded flow UX **6.5**, functionality
**7.5**, aesthetics **6.5**. Its two concrete navigation/copy findings were
corrected and independently rechecked through eight additional interface
assertions. The reviewer did not replace those scores with whole-product claims.

The prepared handover still presents Markdown and CSV source wording awkwardly
and gives generic next steps. Campaign readiness can concatenate field labels
into unnatural sentences. After saving an edited document, the separate editor
feedback can still say to save it. These are explicit next-cycle quality issues,
not release acceptance or a 10/10 result.
